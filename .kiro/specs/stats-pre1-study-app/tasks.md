# Implementation Plan

- [x] 1. プロジェクト基盤を構築する
- [x] 1.1 静的サイト生成環境とテスト環境を初期化する
  - Astro・TypeScript（strict）・Preact統合を備えたプロジェクトを作成し、静的出力でビルドできる状態にする
  - 公開先のサブパスを設定で切り替えられるようにし、全ページ・アセットのリンクがサブパス配下で解決されることを確認する
  - 単体・統合テスト（Vitest）とE2Eテスト（Playwright）の実行環境を整え、サンプルテストが通る状態にする
  - ビルド前にコンテンツ検証と単体テストを実行する一連のスクリプトを用意する
  - _Requirements: 14.1, 14.3_

- [x] 1.2 テーマと共通レイアウトの土台を作る
  - ライト／ダークの配色トークンを定義し、端末のダークモード設定に追従させる
  - 共通ヘッダー（ダッシュボード・分野マップ・公式・分布・演習・復習・計算機へのナビゲーション）とフッターを持つ共通レイアウトを作る
  - スマートフォン幅ではナビゲーションを折り畳み、本文が横スクロールしないレイアウトにする
  - 長いディスプレイ数式のみ個別に横スクロールできるようにする
  - _Requirements: 1.5, 15.1, 15.3_

- [x] 2. コンテンツのスキーマと検証を実装する
- [x] 2.1 大分類・分野・公式カード・分布カタログのスキーマを定義する
  - 大分類（表示順）、分野（所属大分類・概要・関連分布）、公式カード（公式本体・変数・適用条件・導出・注意点・タグ）、分布カタログ（数式・期待値・分散・積率母関数・パラメータ説明・関係・図上の配置）の必須項目と型を定義する
  - IDの形式（英小文字・数字・ハイフン）を検証する
  - 必須項目の欠落や型不一致がファイル名付きのビルドエラーになることをテストで確認する
  - _Requirements: 13.1, 13.3, 13.4_

- [x] 2.2 問題のスキーマを定義する
  - 所属分野（1件以上）・関連公式・難易度・形式（選択式／数値入力式）・出典（オリジナル／年度・問番号の参照）・問題文・解説を必須項目として定義する
  - パラメータ範囲・中間値式・制約式・類題数・正答式・表示桁数・許容誤差・選択肢の任意項目を定義する
  - 選択式では正答の選択肢がちょうど1つであること、数値入力式では正答が定義されていることを検証する
  - _Requirements: 6.3, 6.4, 13.1, 13.3, 13.6, 16.1_

- [x] 2.3 コレクション横断の参照整合性検証を実装する
  - 各コレクション内のID重複を検出する
  - 存在しない分野・公式・分布・大分類への参照、要点本文中の内部リンク記法の参照切れを検出する
  - 対話型分布として指定された分布に数値計算の実装が存在することを検証する
  - 検出結果をファイル名・項目・理由の形式で全件出力し、1件でもあればビルドを失敗させる
  - 不正なフィクスチャを用いた統合テストで、各種エラーが検出されることを確認する
  - _Requirements: 13.2, 13.3, 13.4_

- [x] 3. コンテンツの変換と類題生成を実装する
- [x] 3.1 Markdownの2モード変換と内部リンク解決を実装する
  - 静的ページ用に、数式をビルド時にKaTeXでHTML化する変換を実装する
  - 問題用に、数式をLaTeX文字列のまま保持し、類題の差し込み記号を温存する変換を実装する
  - 要点・公式の本文中の他分野・公式への参照記法を、サブパスを考慮したリンクへ変換する
  - 両モードの出力形式をテストで固定する
  - _Requirements: 2.2, 2.6, 14.3_

- [x] 3.2 ビルド時の安全な式評価環境を用意する
  - 数学関数と分布関数（正規・t・χ²・F分布の確率と分位点、組合せ数、ガンマ関数など）のみを使える式評価環境を作る
  - 外部モジュール読込や任意コード実行に相当する機能を無効化する
  - 代表値が数表と一致することをテストで確認する
  - _Requirements: 7.2, 13.5_

- [x] 3.3 類題の事前生成と検証を実装する
  - 問題IDをシードとして、パラメータ範囲・刻みから値を抽出し、中間値・制約・正答・選択肢の値を順に評価する
  - 制約を満たさない場合は再抽出し、上限回数を超えたら制約充足不能としてビルドを失敗させる
  - 正答が有限値でない場合、選択肢の値が重複する場合、問題文・解説・選択肢に未定義の差し込み記号がある場合にビルドを失敗させる
  - 表示桁数に従って値を整形し、重複しないパラメータ組を指定数（組合せが少なければ全組合せ）まで生成する
  - 同じ入力から常に同じ類題が生成されることをテストで確認する
  - _Requirements: 7.1, 7.2, 7.3, 13.5_

- [x] 3.4 問題バンクと問題索引を出力する

  - 全問題のID・分野・大分類・形式・難易度のみを含む軽量な索引を出力する
  - コンテンツのハッシュをバージョンとして付与する
  - 新しい問題ファイルを追加するだけで索引と分野別バンクに含まれることを統合テストで確認する
  - _Requirements: 13.2, 15.5_
